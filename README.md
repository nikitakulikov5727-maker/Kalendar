# Рабочий календарь — Android-проект

Первый прототип Android-приложения на Kotlin + Jetpack Compose.

## Реализовано в исходниках
- месячный календарь с часами и заработком в ячейке дня;
- локальное хранение записей в SQLite;
- несколько тарифных записей в один день (добавляются по одной без ограничения в интерфейсе);
- расчёт смены через полночь (например, 22:15–06:00 = 7:45);
- ручной ввод длительности;
- итоги по месяцу и произвольному диапазону дат.

## Сборка APK
Требуется Android Studio (JDK 17, Android SDK Platform 35).
Откройте папку проекта в Android Studio и дождитесь синхронизации Gradle.
Затем: Build → Build Bundle(s) / APK(s) → Build APK(s).
APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Минимальная версия Android — 8.0 (API 26). Приложение не требует разрешения на интернет и хранит данные локально.
